# 🚀 AI Space Shooter — Apex Edition

An arcade space combat game built with Python and Pygame, compiled to WebAssembly for direct browser execution.

## 🎮 Live Playable Demo
Play directly in your browser: [https://divyanshb18.github.io/space-shooter-game/](https://divyanshb18.github.io/space-shooter-game/)

---

## ⚡ Features
- **Player Mechanics:** Full 8-directional movement, laser firing system, and power-up collection.
- **Weapon Upgrades:** Triple-laser enhancement with real-time HUD timers.
- **Boss Encounter:** Multi-phase Mothership encounter with custom attack patterns.
- **Visuals:** Dynamic starfield, custom rendering, and particle explosion engines.
- **WebAssembly Ready:** Asynchronous event loop design using `pygbag` for zero-install web gameplay.

---

## 🛠️ Tech Stack
- **Language:** Python 3
- **Core Engine:** Pygame
- **Web Runtime:** Pygbag (WebAssembly / Emscripten)
- **Deployment:** GitHub Pages
